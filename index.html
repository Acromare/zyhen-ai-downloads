接入你的
模型服务。

从服务商取得 API 密钥，在 App 里选择对应的协议并填写地址。能用哪些模型，取决于你的账号权限。

支持的接口

OpenAI 兼容、OpenAI Responses、Claude Messages、Gemini。

模型列表
保存服务配置后自动获取。服务商没有返回列表时，也可以手动填写模型 ID。
密钥和用量
密钥保存在手机的系统安全存储里。对话发送给你选定的服务商，费用按对方的规则结算。
换机与备份
在「设置 → 数据管理」导出对话和偏好。备份不含密钥，换机导入后需重新填写。

第一次怎么安装？

用安卓浏览器下载并打开 APK，在系统提示中确认安装。

装过旧版怎么更新？

保留旧版，打开新版安装包，选择「更新」。也可以在设置中检查更新。

iPhone 可以安装吗？

iOS 暂无公开安装版。
